# Orbwork

A small puzzle game about googly-eyed orblings. Pick them up, drop them into sockets, and figure out the rules of each world by playing.

**Play:** https://bernalj.github.io/orbwork/

Worlds: the Hatchery, the Commons, the Nursery, the Reef, the Queue, the Seesaw and the Lighthouse, most with Remix levels that mix rules between worlds.

It's a single self-contained `index.html`. Progress is saved in your browser. On a phone, use **Add to Home Screen** to play it full screen like an app.

## Desktop / Steam build

The same game also ships as a Windows desktop app (Electron) with Steam achievements and cloud saves. See [STEAM.md](STEAM.md).

```bash
npm install
npm start
```
